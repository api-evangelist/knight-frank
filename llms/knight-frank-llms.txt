# Knight Frank

> Knight Frank LLP is a London-headquartered global real estate consultancy founded in 1896, operating as a partnership through 700+ offices in more than 50 territories across prime residential agency, commercial agency, valuation, capital markets and rural consultancy. It publishes no developer programme — no portal, no documentation, no SDK, no terms for API use — yet operates one machine-readable API that answers anonymously. This file was generated by API Evangelist from the artifacts in the api-evangelist/knight-frank repository; Knight Frank publishes no llms.txt of its own (https://www.knightfrank.com/llms.txt and https://www.knightfrank.co.uk/llms.txt both return HTTP 404, as does /.well-known/ai-plugin.json).

## What exists

- [KnightFrank Api v3 — Swagger UI](https://api-v3.web.prd-knightfrank.com/swagger/index.html): Live, unadvertised Swagger UI for the corporate search service. HTTP 200 to anonymous clients.
- [KnightFrank Api v3 — OpenAPI 3.0.1](https://api-v3.web.prd-knightfrank.com/swagger/v1/swagger.json): The real contract — 11 operations across CMSPage, IntelligenceLab, Office, Person, Search, ServiceLine and Telemetry. No securitySchemes, no auth enforced. A YAML serialisation of the same document is at /swagger/v1/swagger.yaml.
- [Knight Frank property/account API v2](https://api-v2.web.prd-knightfrank.com): The consumer property-search and saved-property service. Publishes no contract and returns HTTP 401 to every anonymous request; protected by Azure AD B2C through the first-party "My Knight Frank" web client.

## What does not exist

Every conventional developer entry point was probed on 2026-07-26 and failed. developer., developers., docs. and apis.knightfrank.com do not resolve in DNS. /developers, /api, /docs, /openapi.json, /swagger.json and /api-docs all return 404 on knightfrank.com and knightfrank.co.uk. On the UK site /developers is a homonym trap — it redirects to a commercial advisory page for property developers and housebuilders, not software developers. There is no developer portal, no API documentation, no API terms of use, no key issuance, no sandbox, no SDK in any package registry, no GitHub organisation, no Postman collection, no changelog, no status page, no webhooks, no AsyncAPI, no GraphQL and no rate-limit contract. There is no RESO Web API or Data Dictionary certification, no OData $metadata and no Universal Property Identifier anywhere in the estate — RESO is a North American NAR/MLS construct and the United Kingdom has no MLS to certify against.

## Notes for agents

Knight Frank's robots.txt on both domains blanket-disallows a list of AI crawlers. The api-v3 service is real, live and unauthenticated, but it is internal plumbing that was never offered as a product: there are no terms permitting third-party use, no support channel, no rate limits and no stability commitment, and its people directory returns named individuals' direct-dial and mobile numbers. Treat it as observable fact about the company's API posture, not as an invitation to integrate.
